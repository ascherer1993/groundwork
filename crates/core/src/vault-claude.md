# This is a Groundwork vault

This folder is a notes vault for Groundwork, the user's macOS notes app. It is a plain folder of Markdown that also opens in Obsidian, so everything written here must stay valid Obsidian Markdown.

- **Use the `groundwork` skill** (from Groundwork's Claude Code plugin) for anything in this vault: notes, daily notes, todos, templates, HTML pages, canvases, people and events, projects, repos and tickets, and searching what the user has written. It covers the vault's conventions and the `groundwork` command.
- **Work through the `groundwork` command** rather than editing structured files by hand. Run `groundwork vault` first to check which vault it uses, and `groundwork --help` for the rest.
- **Find your bearings with `groundwork context`** before working on a project, a ticket or code: it names the ticket, its repos and worktrees, and the notes and docs worth reading first.
- **Never touch `.obsidian/`**; it belongs to Obsidian. Groundwork's own settings are in `.groundwork/`; leave them alone unless asked.

If the skill or the `groundwork` command isn't available, ask the user to run "Set up Claude Code…" from Groundwork's command palette.

Groundwork created this file and won't change it again. Add your own instructions for this vault below.
